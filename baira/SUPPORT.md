# BAIRA support

Use [GitHub issues in this repository](https://github.com/miltoskar/chatgpt/issues) to report a reproducible documentation or scientific-workflow problem, or to suggest an improvement. Prefix issue titles with `[BAIRA]`.

Provide: the software version, a minimal reproducible example, input-data provenance, relevant error text, expected and actual behavior, and whether the problem concerns an installed ChatGPT plugin or a standalone local run.

**Do not post** secrets, access tokens, private research data, medical records, unpublished measurements, or other confidential information in public issues.

Public issues are not a real-time support channel. Availability and response times are not guaranteed.

Scientific findings and AI-generated scientific results require independent user verification.
